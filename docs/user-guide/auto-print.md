# 自动打印用户手册

## 功能介绍

自动打印功能允许系统在业务事件发生时自动打印相关单据，无需手动操作。例如：

- 销售订单确认后自动打印出货单
- 采购订单收货后自动打印入库单
- 收款确认后自动打印收据

## 使用场景

| 场景 | 文档类型 | 触发事件 | 说明 |
|------|----------|----------|------|
| 确认订单后打印 | 销售订单 | 确认时 | 销售订单确认后自动打印 |
| 发货后打印 | 销售订单 | 发货时 | 出货时自动打印装箱单 |
| 收货后打印 | 采购订单 | 收货时 | 收到货物后自动打印入库单 |
| 收款后打印 | 收款凭证 | 确认时 | 收款确认后自动打印收据 |
| 付款后打印 | 付款凭证 | 确认时 | 付款确认后自动打印凭证 |
| 退货审批后打印 | 销售退货 | 确认时 | 退货审批后自动打印退货单 |

## 配置自动打印规则

### 前提条件

1. 已安装并启动打印服务（参见"安装打印服务"章节）
2. 拥有管理员权限
3. 已配置打印模板

### 步骤一：进入自动打印设置

1. 登录 ERP 系统
2. 导航至 **设置** > **打印设置** > **自动打印规则**
3. 点击 **新建规则** 按钮

### 步骤二：配置打印规则

填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **文档类型** | 选择要自动打印的单据类型 | 销售订单 |
| **触发事件** | 选择触发打印的业务事件 | 确认时 |
| **打印模板** | 选择要使用的打印模板（可选，留空使用默认模板） | 默认销售订单模板 |
| **自动打印** | 是否自动发送到打印机 | 是 |
| **打印份数** | 打印的副本数量（1-100） | 1 |
| **打印机** | 指定打印机名称（可选，留空使用默认打印机） | Office LaserJet |

### 步骤三：保存并启用

1. 点击 **保存** 按钮创建规则
2. 新规则默认为启用状态
3. 如需临时禁用，点击规则行的 **禁用** 按钮

### 管理规则

- **编辑规则**：点击规则行的编辑按钮修改配置
- **启用/禁用**：使用开关切换规则状态
- **删除规则**：点击删除按钮移除规则（不可恢复）
- **查看规则**：在列表中查看所有已配置的规则及其状态

## 支持的文档类型和触发事件

### 文档类型

| 文档类型 | 代码 | 说明 |
|----------|------|------|
| 销售订单 | SALES_ORDER | 销售业务订单 |
| 采购订单 | PURCHASE_ORDER | 采购业务订单 |
| 销售退货 | SALES_RETURN | 销售退货单 |
| 采购退货 | PURCHASE_RETURN | 采购退货单 |
| 收款凭证 | RECEIPT_VOUCHER | 收款凭证 |
| 付款凭证 | PAYMENT_VOUCHER | 付款凭证 |
| 销售出库 | SALES_DELIVERY | 销售出库单 |
| 采购入库 | PURCHASE_RECEIVING | 采购入库单 |
| 销售签收 | SALES_RECEIPT | 销售签收单 |
| 盘点单 | STOCK_TAKING | 库存盘点单 |

### 触发事件

| 触发事件 | 代码 | 适用文档类型 |
|----------|------|-------------|
| 创建时 | CREATED | 所有文档类型 |
| 确认时 | CONFIRMED | 销售订单、采购订单、销售退货、采购退货、收款凭证、付款凭证 |
| 发货时 | SHIPPED | 销售订单、销售出库 |
| 收货时 | RECEIVED | 采购订单、采购入库 |
| 完成时 | COMPLETED | 销售订单、采购订单、销售退货、采购退货、盘点单 |
| 付款时 | PAID | 销售订单、采购订单、收款凭证、付款凭证 |

## 安装打印服务

打印服务是运行在本地的独立程序，负责接收打印指令并发送到打印机。

### 系统要求

- 操作系统：Windows 10+、macOS 10.15+、Linux (Ubuntu 20.04+)
- 网络：能够访问 ERP 服务器
- 打印机：已在系统中安装并配置

### 安装步骤

#### Windows

1. 下载 `print-service-windows-amd64.exe`
2. 以管理员身份运行 PowerShell
3. 执行安装：
   ```powershell
   .\install.ps1 -ConfigPath C:\PrintService\config.yaml
   ```
4. 服务将自动启动并开机自启

#### macOS

1. 下载对应架构的二进制文件
   - Intel Mac: `print-service-darwin-amd64`
   - Apple Silicon: `print-service-darwin-arm64`
2. 打开终端执行：
   ```bash
   ./install-mac.sh --config /path/to/config.yaml
   ```

#### Linux

1. 下载 `print-service-linux-amd64`（或 ARM64 版本）
2. 执行安装：
   ```bash
   sudo ./install.sh --config /path/to/config.yaml
   ```

### 配置文件

配置文件使用 YAML 格式。最小配置示例：

```yaml
server:
  api_url: "http://your-erp-server:8080"
  websocket_url: "ws://your-erp-server:8080/api/v1/printing/ws"
  tenant_id: "your-tenant-id"
  api_token: "your-api-token"

printing:
  default_printer: "你的打印机名称"
```

> **重要**：配置文件包含 API Token 等敏感信息，请确保文件权限设置正确（仅所有者可读写）。

### 验证安装

打印服务运行后，可以通过健康检查端点验证：

```bash
curl http://localhost:9999/health
```

返回 `"status": "running"` 表示服务运行正常。

在 ERP 前端，打印服务状态指示器会显示连接状态：
- 🟢 **已连接**：打印服务正常运行
- 🔴 **未连接**：打印服务未启动或网络不通

## 工作流程

```
1. 用户在 ERP 中确认销售订单
          │
2. 系统产生 "SalesOrderConfirmed" 事件
          │
3. 自动打印处理器检查是否有匹配的规则
          │
4. 如果找到启用且 auto_print=true 的规则：
   ├── 使用指定模板渲染文档为 PDF
   ├── 创建打印任务
   └── 通过 WebSocket 通知打印服务
          │
5. 打印服务接收事件
   ├── 下载 PDF 文件
   └── 发送到指定打印机
          │
6. 打印完成 ✓
```

## 常见问题

### Q: 打印服务状态显示"未连接"怎么办？

**A:** 请检查以下几点：
1. 确认打印服务程序是否正在运行
2. 检查配置文件中的 API URL 是否正确
3. 确认网络防火墙是否允许 9999 端口（健康检查）和 8080 端口（API）
4. 查看打印服务日志获取详细错误信息

### Q: 规则已配置但不自动打印？

**A:** 请确认：
1. 规则状态为"已启用"
2. "自动打印"选项已开启（不仅仅是"启用"）
3. 打印服务已连接并运行
4. 打印机在线且可用
5. 查看打印任务列表确认是否有打印记录

### Q: 同一个事件会重复打印吗？

**A:** 不会。系统使用幂等性检查机制（基于 Redis），同一文档的同一触发事件在 24 小时内只会打印一次。如果 Redis 不可用，系统会继续工作但不保证幂等性。

### Q: 可以同时配置多个规则吗？

**A:** 每个文档类型和触发事件的组合只能有一个规则。例如，不能为"销售订单 + 确认时"创建两个不同的规则。

### Q: 打印失败后怎么办？

**A:** 打印失败不会影响业务流程（例如订单确认不会因打印失败而回滚）。您可以：
1. 在打印任务列表中查看失败原因
2. 修复问题后手动重新打印
3. 检查打印服务日志获取详细错误信息

### Q: 如何更换打印模板？

**A:** 编辑对应的自动打印规则，更改"打印模板"字段即可。下次触发时将使用新模板。

### Q: 支持哪些打印机？

**A:** 支持以下协议的打印机：
- **IPP (Internet Printing Protocol)**：大多数网络打印机
- **CUPS**：Linux/macOS 系统上的 CUPS 打印机
- **Windows Print Spooler**：Windows 系统上安装的打印机

### Q: 如何查看打印历史？

**A:** 在 ERP 系统中导航至 **打印管理** > **打印任务**，可以查看所有打印记录，包括状态、打印时间和错误信息。

## API 参考

自动打印规则的 API 端点：

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/v1/printing/auto-rules` | 创建规则 |
| GET | `/api/v1/printing/auto-rules` | 列表查询 |
| GET | `/api/v1/printing/auto-rules/:id` | 获取规则详情 |
| PUT | `/api/v1/printing/auto-rules/:id` | 更新规则 |
| DELETE | `/api/v1/printing/auto-rules/:id` | 删除规则 |
| POST | `/api/v1/printing/auto-rules/:id/enable` | 启用规则 |
| POST | `/api/v1/printing/auto-rules/:id/disable` | 禁用规则 |
| GET | `/api/v1/printing/auto-rules/lookup` | 按类型和事件查询规则 |
| GET | `/api/v1/printing/auto-rules/trigger-events` | 获取文档类型可用的触发事件 |

完整的 API 文档请参考 Swagger：`http://your-erp-server:8080/swagger/index.html`
